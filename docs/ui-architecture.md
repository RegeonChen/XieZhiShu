## 1. 整体布局（三栏工作台）

- **无顶部横栏**（软件名「志书撰写工具」/「隐藏中栏」按钮/版本号/平台信息已移除）。中栏/右栏边界为**悬停高亮切换手柄**：光标放到边界时边界线高亮并出现圆角长方形按钮（内为小三角）——中栏可见时左向小三角、点击隐藏中栏；中栏隐藏时右向小三角、点击恢复中栏（持久化）。
- **左栏（图标导航）**：**资料库 / 撰写 / 设置**（线性图标 + 小字标签，宽度可拖拽）。原「规范」页导航已随 Phase 6.4 移除（规范入口改在撰写工作台头部与第二步内嵌）。
- **中栏（列表，可拖拽宽度、可隐藏）**：资料列表（含网页资料库注册区）/ 撰写任务列表。
- **右栏（工作区）**：资料详情（或标签管理）/ 撰写工作台（三段式向导，左右两栏）/ 设置。
- 新手引导聚光覆盖层（首次启动自动展示，设置页可重新打开，6 步覆盖大模型两种配置/工作区/资料库/演示任务/三步生成）；诊断日志导出入口位于设置页。
- **主题**：设置页「外观（主题）」三选一（简洁明亮 / 明亮+深色 / 古典公文风），以 `data-theme` 注入 `<html>` 切换 CSS 变量，localStorage 持久化记忆。

## 2. 页面清单

### P1 资料库
- **P1.1 资料列表**（中栏）：按标签筛选；资料行显示标题、状态徽标（已就绪/失败/排队中/处理中）、类型（文件/网址）；当前选中项高亮；右键删除（二次确认）；「资料管理」批量模式（全选/删除）；顶部操作——**导入文件 / 整理资料**（LLM 摘要，带说明气泡；无「全部资料」标题，标签管理/资料管理入口并入工具栏「…」菜单）；下方分两段小标题——**网页资料库** / **本地资料库**：工作区路径展示；同步为自动触发（聚焦/进资料库/每分钟/监听增量，带进度条与新文件预处理提示，手动同步按钮已移除）；网页资料库（站点注册/列表/修改/删除，同步为生成汇编时自动触发）。
- **P1.2 资料详情**（右栏）：标题 + 标签 + 状态/类型/来源/时间徽标；LLM 摘要（主题词/关键实体 chips）；正文预览（PDF 查看器 / 图片 / docx HTML 渲染 / 纯文本）。**「复制全文」按钮已于 v0.2.1 移除**。
- **P1.3 标签管理**（中栏三点菜单进入，右栏展示）：新建（相似标签 Top5 建议）/ 添加（批量打标）/ 删除（二次确认）/ 按标签多选交集检索。

### P2 撰写（三段式撰写工作台）
- **P2.1 任务列表**（中栏）：「新建任务」立即创建（标题默认"新建任务"）；列表行显示任务标题 + 文章标题/创建时间；右键重命名/删除（二次确认）。
- **P2.2 撰写工作台**（右栏，核心页面；常驻挂载，切页不丢对话与进度）：
  - 顶部**三步向导**（`writing-stepper`）：① 生成资料汇编 → ② 指定行文规范 → ③ 生成志书初稿。未确认汇编时锁定 Step 2/3（仅可回退）；每步显示状态（待开始/进行中/已完成）与摘要。底部不再有「上一步/下一步」按钮，切换仅靠顶部步骤条。
  - 头部：任务标题 / 文章标题（大模型抓取）/ 任务标题可右键重命名；右侧「规范」入口（回收站按钮左侧并列，打开规范文档库弹窗）。
  - 左栏对话面板（可拖拽宽度，最小 320px）：消息列表（历史持久化）、生成进度条 + 预计剩余时间、流式输出实时显示、AI 回复一键复制、来源引用 `#N` 可点击打开原文；底部输入框——Step 1 主按钮「生成资料汇编」，Step 3 主按钮「生成撰写初稿」，Step 2 自由对话。
  - **预设提示词（2026-09-08 重做）**：输入框上方的胶囊触发器（火花图标 + 文案 + 上向箭头）打开**向上弹出的面板**（`--shadow-lg` + `menu-pop` 动效，点击面板外或 Esc 关闭）；面板内文案区 + 两个分组——**「生成汇编前」**（输入标题与需求：`本次撰写任务的标题为 「……」，具体包括 「……」`）与**「调整现有汇编」**（批量删除 / 增补内容）。每项显示图标 chip、名称、一句说明与模板预览（两行截断），hover 显示「填入」；无资料汇编时「调整现有汇编」一组置灰并标注「生成汇编后可用」。点击任一项把模板**追加**到输入框（不覆盖已输入文字）并自动选中第一个「……」占位符、聚焦输入框，用户可直接键入覆盖。
  - 右栏随步骤切换：**Step 1** `CompilationStep`（资料卡片审阅）/ **Step 2** `StyleGuideEditor`（行文规范 + 可选范本）/ **Step 3** `DraftEditor`（初稿编辑器）。

### P2.3 ① 资料汇编页（CompilationStep）
- 卡片按时间升序（可经「按时间排序」圆钮切换正/反序）；每张卡片显示时间标签 chip、来源文件徽标（`sources:openPath` 打开原文）、正文摘录、备注；操作：编辑 / 删除 / 打开来源（收进右侧「…」下拉菜单）；疑似矛盾卡片加「⚠ 矛盾」标记。
- 矛盾取舍：点击矛盾标记弹出多说法对比弹窗（两说法并列、来源文件链接），用户选择保留某张卡片（采纳）或「忽略」；**未处理完的 `pending` 矛盾会阻止「确认汇编」**。每个说法除「采纳该说法」外还有 **「定位到该段」**：点击后下方资料卡片列表滚动到该说法对应的卡片并短暂高亮（`.compilation-card.is-located`，accent 描边 + 1.8s 脉冲），便于用户就地编辑；卡片已不在当前汇编（被删除/已随取舍排除）时给出明确提示而非静默无反应。
- 资料提纯（2026-09-08 新增，先于「大模型修正」；2026-09-10 收紧口径 + 句读吸附 + 并行）：细读产出的整段卡片会先交给大模型**逐字摘录**与主题相关的句段（严格子串 + 本地校验 + 句读吸附，写通测试口径、不做内容拦截），得到更纯净、更细粒度的卡片集。进度区显示「正在提纯资料（第 i/N 批：筛除与主题无关的句段）…」（批次按 Provider 并发数并行）；生成汇总显示「提纯：253 张 / 96000 字 → …」与「其中 N 张未获提纯结果、已按原样保留」。**提纯是黑箱**：不展示提纯前原文、不支持单独回退（需要退回时用「重新生成汇编」）；超出阶段时间预算（900s）时剩余卡片按原样保留并在汇总提示。
- 大模型修正（2026-09-08 改版）：提纯之后、「矛盾扫描」之前自动做一轮修正（补全残缺表述、静默补齐缺失时间戳），**默认全部应用**；被修正的卡片 meta 行显示可点击标记 **「✎ 经过大模型修正」**（回退后转为灰色 **「↺ 已回退到修正前」**），点击打开「大模型修正详情」弹窗——修正前原文（灰 + 删除线）、修正后文本（绿）、修正理由，底部按钮按状态为「回退到修正前」/「重新应用修正」；卡片「…」菜单也提供「修正详情」入口。修正不再进入回收站，时间戳补齐不在修正记录内（不可回退）。**2026-09-10**：时间戳补齐范围扩为「时间为『无』**或时间缺少年份**」（如 `5 月 19 日`、`7—9 日`），提示词要求时间标注**必须含年份**（依据上下文/来源年鉴年份推断）且不得编造，本地只采纳含 4 位年份的结果；残缺判定补充「句子起点/终点不完整」「指代不明」「缺主语」，并明确**优先补全而非删除**。
- 大模型异常中断（Phase 6.x）：窗口细读 / **提纯** / **大模型修正** / 矛盾扫描时若大模型返回中断（余额不足/网络等），左栏对话进度区展示**中断提示卡片**（阶段 + 原因 + 冻结进度），并给出 **「尝试继续」** 按钮；点击后从断点续跑（复用已完成窗口与已完成的提纯/修正批次，仅重读失败或未完成的窗口、重跑未完成批次、继续扫描剩余矛盾批次）。会话内断点续传，重新生成汇编仍可覆盖重建；提纯/修正阶段超出时间预算时在生成汇总中提示「未完成」。
- 顶部工具栏：撤销 / 恢复（快照 + 栈，会话内）、按时间排序（正反序循环）、回收站（垃圾桶圆钮，展示**资料卡片 / 矛盾两类**并可恢复）。
- 「确认汇编，进入下一步」：`pending` 矛盾未处理完则被阻止并提示；确认后 `status='finalized'`，锁定卡片（可「重新生成汇编」覆盖回到 drafting）。

### P2.4 ② 行文规范页（StyleGuideEditor，Phase 6.4.1/6.4.2）
- 文本编辑器（textarea）展示当前默认规范；右上「导入已有规范作为底稿」（选择已保存规范 → 二次确认 → 替换全文）；右下「保存规范」——选择保存方式（已有规范 →「覆盖现有规范」/ 空白「+」→「另存为新规范」）；每篇规范可设为默认/重命名/删除。
- **参考范本（Phase 6.4.2，仅 taskId 场景）**：工具栏「添加范本」置于「导入已有规范作为底稿」左侧；点击展开可折叠范本窗口（文本框，防抖自动保存到任务 `model_text`）。
- **「下一步」按钮**：「保存规范」右侧，仅第二步 taskId 场景显示；若当前规范相对已保存内容有修改则弹二次确认（未保存修改不采用），确认后进入第三步并自动触发生成初稿（已有初稿则仅切换页面）。

### P2.5 ③ 生成初稿页（DraftEditor，Phase 6.6）
- 深改 TipTap 编辑器：正文衬线（宋体/Noto Serif SC）、固定左右留白随右栏宽度铺开、标题层级、页边距、`@media print` 打印友好、页脚字数统计、撤销重做工具栏、保存状态。
- 保留 Markdown 存储 / 800ms 防抖整稿保存 / `draft:updateContent` / 右键菜单（剪切/复制/粘贴/全选 + 询问文段来源）；矛盾标注扩展保留以兼容旧稿。
- 初稿来源仅到**汇编卡片层**（正文不逐段标注来源）。
- **强制三步式（Phase A/B）**：生成/重生成初稿必须基于**已确认（`finalized`）的资料汇编**；未确认时前端拦截并提示「请先确认资料汇编」，不再走旧版单次检索生成链路。
- **整段化切片（Phase A/B）**：资料汇编的候选以**整段**为单元，超长段（默认 >1000 字）仅按句折成 ≤上限 的子块并共享同一段；**粗细筛以整段为单位保留/剔除**（段内任一子块有信号 → 整段保留），最终**资料卡片 = 整段/整子块原文**（AI 不再按事实切分）。

### P4 设置
- **中栏 = 设置导航**（`SETTING_SECTIONS`，点击平滑滚动 + scroll-spy 高亮）：**总览 / 外观（主题）/ 工作区资料库 / 预设大模型 / 步骤默认模型 / LLM Provider** 六项。
- **右栏（卡片式区块）**：
  - 总览渐变卡（当前 Provider / 工作区状态速览 + 新手教程 / 导出日志入口 + **「长任务时保持电脑唤醒」开关**（Phase A，默认开启））；
  - 外观（主题）：三套主题（简洁明亮 / 明亮+深色 / 古典公文风）单选，持久化记忆；
  - 工作区资料库：选择/清除文件夹、存量迁移、当前路径 + 配置状态 chip；
  - 预设大模型：内置预设卡片（一键预填 / API key 教程弹窗 + 打开注册页）；
  - 步骤默认模型（Phase 6.8）：两个下拉分别设置第 1 步（汇编）默认 Provider、第 3 步（初稿）默认 Provider，选项 = 已配置 Provider + 「未设置（回退任务/全局）」；
  - LLM Provider 配置：新建/编辑/删除/测试连接；密钥仅显示「已设置」；每个 Provider 可配置**「并发窗口数」**（Phase B，默认 4、范围 1–8），用于资料汇编 AI 细读/矛盾扫描并行。

## 3. 关键交互流程

1. **资料收集**：设置工作区 → 文件增删改自动同步入库 → 打标签 / 注册网页资料库（生成汇编时自动检索相关文章）。
2. **撰写闭环（三段式）**：新建任务 → 输入撰写要求 → ① 生成资料汇编（召回 + AI 细读 + **提纯** + **大模型修正** + 矛盾标注）→ 审阅/取舍 → 确认 → ② 指定行文规范（可选范本）→ ③ 生成初稿（基于已确认汇编的 kept 卡片 + 默认规范 + 可选范本）→ 编辑保存。
3. **矛盾取舍**：在①单击矛盾标注对比弹窗采纳（保留某卡片）/ 忽略；未处理完的 `pending` 矛盾阻止进入下一步。
4. **来源询问**：③右键选中文段「询问文段来源」→ 回复中 `#N` 渲染为可点击来源链接（`sources:openPath` 打开原文）。

## 4. 状态与体验原则

- 每个页面必须处理五态：加载（spinner）/ 空数据 / 成功 / 部分失败 / 错误（沿用 AGENTS.md 编码约定）。
- **溯源可见性**：文段来源询问（右键）与矛盾弹窗来源链接，点击用系统默认软件打开原文。
- **人工主导提示**：矛盾裁定、文段修改、终审定稿由人工完成；AI 生成内容全程可溯源。
- **按步骤默认模型**：第 1 步（汇编）/ 第 3 步（初稿）/ 对话与来源询问分别按设置页「步骤默认模型」解析（任务固定 → 步骤默认 → 全局当前）。
