# UI 信息架构与页面清单（docs/ui-architecture.md）

> 状态：与代码同步维护（2026-08-19 整理）。布局采用三栏工作台：左栏图标导航 / 中栏列表 / 右栏工作区；撰写工作台为常驻挂载的左右两栏布局。

## 1. 整体布局（三栏工作台）

- **顶栏**：品牌标识 + 应用标题 + 当前功能区标题；右侧中栏显隐切换按钮（持久化）+ 版本/平台信息。
- **左栏（图标导航）**：资料库 / 撰写 / 规范 / 设置（线性图标 + 小字标签，宽度可拖拽）。
- **中栏（列表，可拖拽宽度、可隐藏）**：资料列表（含网页资料库注册区）/ 撰写任务列表。
- **右栏（工作区）**：资料详情（或标签管理）/ 撰写工作台（正文编辑器 + 对话面板左右两栏）/ 写作规范管理 / 设置。
- 新手引导聚光覆盖层（首次启动自动展示，设置页可重新打开）；诊断日志导出入口位于设置页。

## 2. 页面清单

### P1 资料库
- **P1.1 资料列表**（中栏）：按标签筛选；资料行显示标题、状态徽标（已就绪/失败/排队中/处理中）、类型（文件/网址）；当前选中项高亮；右键删除（二次确认）；「资料管理」批量模式（全选/删除）；顶部操作——导入文件 / 整理资料（LLM 摘要，带说明气泡）；工作区路径展示；同步为自动触发（聚焦/进入资料库/每分钟/监听增量，带进度条与新文件预处理提示，手动按钮已移除）；网页资料库（站点注册/列表/删除/手动同步）。
- **P1.2 资料详情**（右栏）：标题 + 标签 + 状态/类型/来源/时间徽标；LLM 摘要（主题词/关键实体 chips）；正文预览（PDF 查看器 / 图片 / docx HTML 渲染 / 纯文本）；「复制全文」按钮。
- **P1.3 标签管理**（中栏三点菜单进入，右栏展示）：新建（相似标签 Top5 建议）/ 添加（批量打标）/ 删除（二次确认）/ 按标签多选交集检索。

### P2 撰写
- **P2.1 任务列表**（中栏）：「新建任务」立即创建（标题默认"新建任务"）；列表行显示任务标题 + 文章标题/创建时间；右键重命名/删除（二次确认）。
- **P2.2 撰写工作台**（右栏，核心页面；常驻挂载，切页不丢对话与进度）：
  - 头部：任务标题、文章标题（大模型抓取）、「重新生成初稿」（danger + 二次确认）。
  - 左栏对话面板（可拖拽宽度，最小 320px）：消息列表（历史持久化）、生成进度条 + 预计剩余时间、流式输出实时显示（2026-08-19）、AI 回复一键复制、来源引用 `#N` 可点击打开原文；底部工具条——大模型选择（跟随全局/任务固定）；输入框：生成前主按钮「生成初稿」，生成后「发送」。
  - 右栏正文编辑器（TipTap 连续整稿）：工具栏（粗体/斜体/下划线/标题/列表/表格增删/撤销重做/矛盾/警告/复制全文）；800ms 防抖自动保存；页脚保存状态 + 字数统计；正文内嵌矛盾标注 chip（点击打开对比弹窗）；右键选中文段「询问文段来源」。
  - 矛盾对比弹窗：单条模式（主题/类型/状态、正文定位、各说法 + 来源文件链接、采纳[正文本地修订]/忽略）；总览模式（全部矛盾含状态）；警告清单（不在正文的矛盾，仅查看/忽略）。采纳支持撤销/重做回退。

### P3 写作规范（已移除，Phase 6.4）
> **Phase 6.4：整个「写作规范 skills」模块（规范页 / `skills:*` IPC / `writing_skills` 表 / 部类细则与通用规范选择）已删除**；改为共享的默认行文规范 `DEFAULT_STYLE_GUIDE`（合并「志书文体文风」+「志书行文规则」），在撰写第二步「指定行文规范」展示，并在生成初稿时作为全局写作约束注入。

### P4 设置
- **中栏 = 设置导航**（2026-08-19）：总览 / 工作区资料库 / 预设大模型 / Provider 四个区块条目，点击平滑滚动定位，滚动时 scroll-spy 高亮当前区块。
- **右栏（卡片式区块）**：总览渐变卡（当前 Provider/工作区状态速览 + 新手教程/导出日志入口）→ 工作区资料库（选择/清除文件夹、存量迁移、当前路径 + 配置状态 chip）→ 预设大模型（三条预设卡片：使用此模型一键预填 / 获取 API key 教程弹窗 + 打开注册页）→ LLM Provider 配置（新建/编辑/删除/测试连接/设为当前；密钥仅显示"已设置"）。

## 2.5 Phase 6 撰写工作台（三段式撰写重构，2026-08-25 规划）

> 三个环节为**三个独立页面**：用户只通过撰写工作台顶部的**三步向导**点击切换显示（每次只渲染当前环节页面，底部不再有「上一步 / 下一步」按钮）；对话框贯穿三个环节。发布版内置**三套主题切换**（简洁明亮 / 明亮+深色 / 古典公文风，通过 data-theme 注入 `<html>`，设置页「外观（主题）」区块三选一，localStorage 持久化记忆）。

- **顶部步骤条**：① 生成资料汇编 → ② 指定行文规范（预留）→ ③ 生成志书初稿；每步显示状态（待开始 / 进行中 / 已完成）与摘要。
- **① 资料汇编页**：右栏卡片列表（时间升序、时间标签、来源徽标、可打开来源、编辑/删除、疑似矛盾标记）+ 候选/卡片/矛盾统计；点击矛盾标记弹出对比弹窗（两说法并列、采纳保留某张卡片/忽略）；「确认汇编」前校验无未处理矛盾，确认后进入②。左栏对话框可就汇编与 AI 对话。**Phase 6.4.3 语义补全/修订**：生成汇编后自动进行一次 LLM 二次加工，表意不明/疑似残缺的卡片显示绿色边框 + 原摘录/补全文本对比 + 原因，用户可「采纳该修订 / 不用」；采纳后卡片摘录改为补全文本，已拒绝的卡片不再显示。右上角「回收站」按钮统一展示矛盾与语义补全条目并可恢复。
- **② 行文规范页（规范文档库，Phase 6.4.1）**：`StyleGuideEditor` 文本编辑器展示当前默认规范；右上角「导入已有规范作为底稿」（选择已保存规范 → **二次确认** → 替换编辑器全部文本）；右下角「保存规范」——弹出「选择保存方式」：已有规范列表 + 空白「+」；点已有项 → 提示「选择覆盖现有规范」→ 覆盖；点「+」→ 提示「另存为新规范」→ 输入名称另存。每篇规范可「设为默认 / 重命名 / 删除」。头部另有「规范」入口按钮（回收站按钮左侧并列），点击弹出同款规范化弹窗（弹窗高度固定 80vh，文本编辑区随高度拉大）。**Phase 6.4.2 增加「添加范本」**：该按钮位于「导入已有规范作为底稿」左侧；点击展开**范本窗口**（可折叠，展开/收起逻辑参考第一步矛盾窗口）——内部为文本框，用户可录入自己的志书示例正文（任务级、可选），录入自动防抖保存到任务；第三步生成初稿时，该范本与行文规范、资料汇编一并作为提交物（以【参考范本】注入）。**Phase 6.3 落地**：底部「上一步/下一步」按钮移除，导航只用顶部三步向导；**「保存规范」按钮右侧新增「下一步」**——若当前规范文本相对已保存内容有修改，点击会弹二次确认（提示未保存修改将不会被采用），确认后进入第三步；否则直接进入第三步（自动按已确认汇编 + 默认规范 + 可选范本组织提交物，生成进度与结果在左侧对话框体现）。
- **③ 生成初稿页**：深改 TipTap 编辑器（衬线正文排版、标题层级、页边距、字数统计、撤销重做、保存状态）+ 流式输出正文 + 生成进度；初稿来源仅到汇编卡片层（正文不逐段标注来源）。

## 3. 关键交互流程

1. **资料收集**：设置工作区 → 文件增删改自动同步入库（或手动同步）→ 打标签 / 注册网页资料库。
2. **撰写闭环**：新建任务 → 输入撰写要求（可先智能匹配规范）→「生成初稿」（自动整理摘要 → 网页检索 → RAG 检索 → 矛盾扫描 → 流式生成 → 矛盾定位，全程进度条）→ 正文编辑/矛盾取舍/自由对话。
3. **矛盾取舍**：点击正文标注或工具栏「矛盾/警告」→ 对比弹窗采纳（正文本地修订、可撤销）/ 忽略。

## 4. 状态与体验原则

- 每个页面必须处理五态：加载（spinner）/ 空数据 / 成功 / 部分失败 / 错误（沿用 AGENTS.md 编码约定）。
- **溯源可见性**：文段来源询问（右键）与矛盾弹窗来源链接，点击用系统默认软件打开原文。
- **人工主导提示**：矛盾裁定、文段修改由人工完成；AI 生成内容全程可溯源。
