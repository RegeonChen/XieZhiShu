# UI 信息架构与页面清单（docs/ui-architecture.md）

> 状态：规划产物（2026-08-03），对应 `PLAN.md` Task 1.1（导航壳/页面骨架）的布局依据。
> 布局采用三栏工作台：左栏导航 / 中栏列表 / 右栏工作区。

## 1. 整体布局（三栏工作台）

- **顶栏**：当前上下文标题 + 全局操作（导入文件、添加信源、LLM Provider 状态入口）。
- **左栏（导航）**：一级功能入口 —— 资料库 / 撰写 / 范本 / 设置；资料库下二级：所有资料、按标签。
- **中栏（列表）**：随左栏选中变化 —— 资料列表 / 撰写任务列表。
- **右栏（工作区）**：详情或工作台 —— 资料预览 / 撰写工作台（含片段审核）。
- 中栏与右栏之间可拖拽调整宽度。

## 2. 页面清单

### P1 资料库
- **P1.1 资料列表**（中栏）：支持按标签筛选与关键词搜索；资料行显示标题、标签、状态徽标（解析中 / 失败可重试）。
- **P1.2 导入与抓取**（右栏/弹窗）：
  - 文件导入：多选文件、批量解析进度（逐文件成功/失败反馈）。
  - 添加信源 URL：输入网址并抓取；白名单校验失败给出可读提示。
- **P1.3 资料详情**（右栏）：清洗后正文预览、原文查看、标签编辑、来源信息（文件路径 / URL + 抓取时间）。
- **P1.4 范本管理**：范本列表、导入单个文件、删除（二次确认，提示引用任务自动失去关联）、篇目层级结构查看、体例特征摘要（Phase 3.3 Task 3.3.1：统计 + 可折叠行文范例）。

### P2 撰写
- **P2.1 新建撰写任务**（右栏表单）：标题输入、文件范围选择（手动勾选资料 或 选择标签，二选一）、范本选择；空范围不可提交。
- **P2.2 撰写工作台**（右栏，核心页面）：
  - 参考范本选择器（Phase 3.3 Task 3.3.2）：下拉选择/更换任务关联范本；未生成初稿时可改，初稿已生成后锁定。
  - 生成初稿：loading 态（"正在检索资料、生成中…"）。
  - 片段化展示：每个片段可展开"来源"（来源标题 + 位置 + 原文摘句，点击可跳转查看对应资料）；AI 生成片段与人工修改片段以样式区分。
  - 整稿编辑器（Phase 3.1：TipTap 所见即所得，Markdown 存储、防抖自动保存）。
  - 内嵌矛盾标注（Phase 3.7）：正文中 `【矛盾#N】` 标记加载为不可编辑的 ⚠️ 标注 chip（点击打开该矛盾的对比弹窗）；工具栏「矛盾」按钮显示待处理数，点击打开矛盾总览。
  - 矛盾对比弹窗（Phase 3.7，2026-08-11 重构）：单条模式并列展示各说法卡片（说法原文 + 来源文件链接[编号 + 标题 + 「打开」] + 正文定位片段）；采纳时**不调用大模型**——定位审查（生成阶段）已为每个说法预生成"采纳替换文句"，主进程本地替换该矛盾正文原句（`draft_quote` 起止定位 → 采纳说法 `replacement`）并移除 `【矛盾#N】` 标注，成功后正文即时刷新、被采纳说法置顶高亮；总览模式列出全部矛盾（含状态与待处理数）。
  - 资料矛盾警告（2026-08-11）：定位审查确认**不在正文**的矛盾 → 工具栏「警告」按钮（与「矛盾」并列）→ 警告清单，展示各说法与来源文件（资料库潜在风险），可忽略；不提供采纳修订、不影响正文。
  - 文段来源询问（Phase 3.7，2026-08-11 增强）：选中正文文段 → 右键「询问文段来源」→ 自动发送到下方对话面板（user 消息带「文段来源询问」标签）；优先本地逐字匹配，未命中时**结合初稿生成时实际使用的检索材料**让大模型溯源（正文被改写后仍可推断同源文件）；回复中 `#N` 来源引用渲染为可点击链接（点击用系统默认软件打开原文）。
  - 审核操作入口：
    - 矛盾提示：多来源并排对比视图，选择采纳某一来源的记述（可填备注）。
    - 文段编辑：就地修改。
- **P2.3 审核模式**：与 P2.2 合并为同一视图的"审核态"，不单独成页。

### P3 设置
- **P3.1 LLM Provider 配置**：新增 / 编辑 / 删除 Provider（API 地址、密钥、模型），连通性测试；密钥只显示"已设置"状态。
- **P3.2 通用设置**：数据目录、界面偏好。

## 3. 关键交互流程

1. **资料收集**：导入/添加 → 解析状态反馈（成功 / 失败可重试）→ 打标签。
2. **撰写闭环**：新建任务（标题 + 范围 + 范本）→ 生成初稿 → 逐片段审核（来源 / 矛盾 / 编辑）。
3. **矛盾取舍**：正文标注点击或「矛盾」按钮 → 对比弹窗选择采纳（正文本地修订）/ 忽略 → 撤销可恢复。

## 4. 状态与体验原则

- 每个页面必须处理五态：加载 / 空数据 / 成功 / 部分失败 / 错误（沿用 AGENTS.md 编码约定）。
- **溯源可见性**：片段来源默认折叠、点击展开；来源图标区分文件 / 网址。
- **人工主导提示**：AI 生成与人工修改内容样式区分（`aiGenerated`），符合"依靠不依赖、赋能不替代"。

## 5. 导航壳落地范围（Task 1.1）

脚手架阶段先落地：三栏布局骨架 + 顶栏 + 左栏一级导航（资料库 / 撰写 / 范本 / 设置）+ 各页面空态占位 + 页面路由切换；各 Phase 再填充具体页面内容。
