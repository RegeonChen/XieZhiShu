# UI 信息架构与页面清单（docs/ui-architecture.md）

> 状态：规划产物（2026-08-03），对应 `PLAN.md` Task 1.1（导航壳/页面骨架）的布局依据。
> 布局采用三栏工作台：左栏导航 / 中栏列表 / 右栏工作区。

## 1. 整体布局（三栏工作台）

- **顶栏**：当前上下文标题 + 全局操作（导入文件、添加信源、LLM Provider 状态入口）。
- **左栏（导航）**：一级功能入口 —— 资料库 / 撰写 / 版本管理 / 设置；资料库下二级：所有资料、按标签、范本。
- **中栏（列表）**：随左栏选中变化 —— 资料列表 / 撰写任务列表 / 版本列表。
- **右栏（工作区）**：详情或工作台 —— 资料预览 / 撰写工作台（含片段审核）/ 版本对比。
- 中栏与右栏之间可拖拽调整宽度。

## 2. 页面清单

### P1 资料库
- **P1.1 资料列表**（中栏）：支持按标签筛选与关键词搜索；资料行显示标题、标签、状态徽标（解析中 / 失败可重试）。
- **P1.2 导入与抓取**（右栏/弹窗）：
  - 文件导入：多选文件、批量解析进度（逐文件成功/失败反馈）。
  - 添加信源 URL：输入网址并抓取；白名单校验失败给出可读提示。
- **P1.3 资料详情**（右栏）：清洗后正文预览、原文查看、标签编辑、来源信息（文件路径 / URL + 抓取时间）。
- **P1.4 范本管理**：范本列表、上传解析、篇目层级结构查看。

### P2 撰写
- **P2.1 新建撰写任务**（右栏表单）：标题输入、文件范围选择（手动勾选资料 或 选择标签，二选一）、范本选择；空范围不可提交。
- **P2.2 撰写工作台**（右栏，核心页面）：
  - 生成初稿：loading 态（"正在检索资料、生成中…"）。
  - 片段化展示：每个片段可展开"来源"（来源标题 + 位置 + 原文摘句，点击可跳转查看对应资料）；AI 生成片段与人工修改片段以样式区分。
  - 审核操作入口：
    - 矛盾提示：多来源并排对比视图，选择采纳某一来源的记述（可填备注）。
    - 事件缺失：手动补写，或导入新资料后调用 AI 生成并插入片段。
    - 文段编辑：就地修改。
  - 底部"确认第 n 稿 → 生成第 n+1 稿"按钮（明确展示当前版本号）。
- **P2.3 审核模式**：与 P2.2 合并为同一视图的"审核态"，不单独成页。

### P3 版本管理
- **P3.1 版本列表**（中栏）：第 0 / 1 / 2…稿，含时间与状态。
- **P3.2 版本对比**（右栏）：任意两稿的片段级 diff 视图。
- **P3.3 回滚**：确认对话框 → 回滚到目标版本 → 右栏切换到回滚后内容。

### P4 设置
- **P4.1 LLM Provider 配置**：新增 / 编辑 / 删除 Provider（API 地址、密钥、模型），连通性测试；密钥只显示"已设置"状态。
- **P4.2 通用设置**：数据目录、界面偏好。

## 3. 关键交互流程

1. **资料收集**：导入/添加 → 解析状态反馈（成功 / 失败可重试）→ 打标签。
2. **撰写闭环**：新建任务（标题 + 范围 + 范本）→ 生成初稿 → 逐片段审核（来源 / 矛盾 / 缺失 / 编辑）→ 确认 → 第 n+1 稿。
3. **版本闭环**：查看版本列表 → 对比差异 → 回滚（确认后内容切换）。

## 4. 状态与体验原则

- 每个页面必须处理五态：加载 / 空数据 / 成功 / 部分失败 / 错误（沿用 AGENTS.md 编码约定）。
- **溯源可见性**：片段来源默认折叠、点击展开；来源图标区分文件 / 网址。
- **人工主导提示**：AI 生成与人工修改内容样式区分（`aiGenerated`）；确认按钮明确标注版本号，符合"依靠不依赖、赋能不替代"。

## 5. 导航壳落地范围（Task 1.1）

脚手架阶段先落地：三栏布局骨架 + 顶栏 + 左栏一级导航（资料库 / 撰写 / 版本管理 / 设置）+ 各页面空态占位 + 页面路由切换；各 Phase 再填充具体页面内容。
