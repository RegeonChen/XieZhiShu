# 志书撰写工具 v0.5.0

> 本次是**可信度与可用性版本**：核心是"汇编里的每一段都必须有逐字依据"（此前允许无依据段落落库），
> 并修掉了三处用户实测发现的严重问题（**张冠李戴**、**来源错挂**、**高亮错位**），另外把整合提取的重试成本降下来、
> 把设置页「建立缓存与索引」从"文字堆砌"重做成数字与进度卡片。**数据库迁移仍是 001–052，本版无新增迁移。**
> **功能范围（重申）**：目前仅实现到「生成汇编」功能区，**「撰写初稿」功能尚未实现**。
> **安装包**：`XieZhiShu-Setup-0.5.0-x64.exe`（Windows x64，NSIS，**含本地嵌入模型 BGE-small-zh-v1.5**；未签名，安装时如提示"未知发布者"请选择"仍要运行"）。

---

## 一、汇编可信度：证据成为门槛（重要口径变化）

用户实测发现两类严重问题并已修复：

1. **张冠李戴**：一张卡片把 A 学校的办学规模（60 个班 / 3000 人 / 142 亩）写到了 B 学校（长乐高级中学）头上，还补了原文没有的"营前街道 / 150 亩 / 8 万平方米"。
2. **来源错挂**：内容出自 2021 年的一篇网页报道，却被挂到"年鉴 2025 第 249 页"，点开当然找不到出处。

修复方式（取代 2026-10-03 的"证据只作充分度"口径）：

- **归属由证据反查**：把段落的逐字引文在本批所有来源的完整正文里定位，**命中哪个来源就归哪个**；一个都命中不了（或模型没给引文）→ **这张卡不落地**。宁可少一段，不留无据段。
- **数字要有上下文**：数字不仅要"出现过"，紧跟的单位/量词也要对得上——「增加学位 3600 **个**」不再能拿年鉴里的「电线电缆 3600 **余米**」充数。
- **提示词卫生**：删掉示范句里的具体数字（实测被模型整段搬到别的学校上），并明确"不得补写原文没有的面积/班数/容量/选址"。

实测效果（同一份材料）：**73 段**（旧口径）→ **197 段**（新口径，来自 5 本年鉴 + 86 篇网页），逐字依据命中率 **197/197 = 100%**，两类问题不再出现。

## 二、来源定位：高亮落在正确那句

- **块内优先收窄**：引文只在锚点块内找，不再全文首次命中；**短引文（<8 字）不再参与收窄**（此前会把高亮缩到"共享"两个字）。
- **页内相似兜底**：卡片被模型改写、块内找不到时，在同页内按 bigram 相似度找最接近的一句。
- **用 PDF 页面自己的文字层画高亮**（关键修复）：此前用 `cleaned_text` 的页内偏移画，而三栏排版的年鉴里两套坐标并不一致，必然错位；现在先在本页文字项里定位，找不到才退回旧偏移。
- **界面如实说精度**：近似匹配显示「该段文字与原文不完全一致，已定位到同页最接近的一句」；只到整块时显示「已定位到该段所在位置（约 500 字范围，未精确到句）」。

## 三、整合提取：把重试成本降下来

实测一轮 197 段耗 **88 次**提取调用（约 3 倍重试）——根因是一批 30 张卡的 JSON 超过模型输出上限被截断，而"换温度重试"只会再截断一次。

- 显式设置输出上限（6,000 token），提取批上限 **30 张 / 12,000 字 → 12 张 / 6,000 字**；
- **输出被截断时不再重试、直接对半拆**；
- 生成汇总里新增「换温度重试 N 次、因输出截断直接拆分 M 批」，成本可见。

## 四、设置页「建立缓存与索引」界面重做

从 11 段灰字堆叠改为四层结构：

- **四个数字块**：待建立网页 / 已缓存正文 / 待索引本地 / 无可用正文（千分位）；
- **状态横幅**：运行中（蓝）/ 已完成（绿，含「建立完成，可以开始生成汇编了」与完成时间）/ 已停止（灰）/ 失败（红）；
- **两张并排进度卡**：网页正文缓存、本地资料库索引（进度条 + 关键数字 + 状态章）；
- **「更多设置」折叠**：清单发现、抓取档位、站点概况、缓存占用与清空、引擎自检——功能一个没少，只是不再抢占视线。

## 五、其他修复

- **删除任务不再卡住界面**：删除改为分批执行（每批约 190ms 就交还主进程），此前删一个 1,020 篇来源的任务会让整个界面僵住约 1.6 秒；删除后顺带回收 WAL。
- **预检框文案**：新任务还没有网页来源时不再显示"网页 0 段"（会被误读为"没有网页材料"），改为「网页：生成时按区间重筛（未计入本估算）」。

## 六、安装与升级

1. 运行 `XieZhiShu-Setup-0.5.0-x64.exe`（未签名，Windows 可能提示"未知发布者"）。
2. **覆盖安装即保留原有数据**（数据库在 `%APPDATA%\xie-zhishu`）；本版无新迁移。
3. 升级后建议**用同一份材料重跑一次汇编**，以享受"证据门槛"带来的可信度提升（旧汇编里的段落不会自动重校验）。

## 七、已知限制（摘要）

- **撰写初稿尚未实现**（导航已置灰并标注「开发中」）。
- 证据门槛会**丢弃没有逐字依据的卡片**：同一份材料重跑，段数可能比旧版**少 10%–15%**，这是有意的取舍。
- 站点发现撞安全阀（300 页 / 6 层 / 3 分钟）时会如实提示"还有列表页没走完"。
- 安装包未做代码签名；本地向量模型不可用时自动降级为纯词法检索。

# 志书撰写工具 v0.4.1

> 本次是**口径对齐的补丁版本**：v0.4.0 的文档里已经写明"功能只到生成汇编"，但界面上还留着一个**可以点进去**的「撰写初稿」入口——文档与界面自相矛盾。本版把界面、新手引导与 README 统一到同一个说法上。**没有改动数据、数据库迁移与生成逻辑**（迁移仍是 001–052，本版无新增）。
> **功能范围（重申）**：目前仅实现到「生成汇编」功能区，**「撰写初稿」功能尚未实现**。
> **安装包**：`XieZhiShu-Setup-0.4.1-x64.exe`（Windows x64，NSIS，**含本地嵌入模型 BGE-small-zh-v1.5**；未签名，安装时如提示"未知发布者"请选择"仍要运行"）。

---

## 一、界面：「撰写初稿」入口置灰

- 左侧导航中的「撰写初稿」**置灰并标注「开发中」**，点击无效。
- 悬停给出一句明确提示：「撰写初稿」功能尚未实现（开发中）：当前版本请使用「生成汇编」，并导出资料汇编。
- 导航与新手引导的**页面切换对置灰项一律拒绝**，避免被程序化地切进不可用页面。

## 二、新手引导

- **末步不再跳到「撰写初稿」**，改为指向「生成汇编」，文案重写为只讲已实现的两段：新建任务 → 生成并审阅资料汇编 → 对话修改 → 导出汇编。
- 「演示任务」「了解资料库」两步去掉已不成立的描述（"两个功能区各有一份演示任务"、"已预置志书初稿"等）。
- 末步补上关键提醒：**生成前先在 设置 →「建立缓存与索引」把网页正文缓存与本地索引建好**，否则点「生成汇编」会被闸门拦住（这是刻意的严格设计）。

## 三、README 按当前功能设计重写

旧 README 还停留在**已经删除的**两步管线（资料提纯 + 大模型修正），并把初稿写作当成已交付。本版按现状重写，并在文首明确功能边界：

> **目前仅实现到「生成汇编」功能区，「撰写初稿」功能尚未实现。**

README 同时补齐了当前需要用户知道的内容：安装包**内含本地嵌入模型**、首次/升级后先「建立缓存与索引」、网页资料库的**多站点与自动同步清单**、站点发现规模**自适应（收益饱和）**、生成前的**严格闸门**、以及"删除资料会同步删缓存"等口径。

## 四、安装与升级

1. 运行 `XieZhiShu-Setup-0.4.1-x64.exe`（未签名，Windows 可能提示"未知发布者"）。
2. **覆盖安装即保留原有数据**（数据库在 `%APPDATA%\xie-zhishu`）；首次启动自动执行迁移（本版无新迁移）。
3. 若您还没建过缓存/索引：升级后第一次点「生成汇编」会被**拦住并引导**去 设置 →「建立缓存与索引」点「建立」。这是刻意设计，不是故障。
4. 网页资料库各站点可点一次「同步清单」，确认「清单 N 条 / 实测发现 N 页」正常。

## 五、已知限制（摘要）

- **撰写初稿尚未实现**（本版已在界面上标明）。
- 站点发现撞安全阀（300 页 / 6 层 / 3 分钟）时会**如实提示"还有列表页没走完"**；需要更全请在设置页切手动并调高上限。
- 「无可用正文」标记目前是"永不再试"（站点删除的老文章重试无意义；临时故障的情形暂无重试入口）。
- 安装包未做代码签名；本地向量模型不可用时自动降级为纯词法检索。
